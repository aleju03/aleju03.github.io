# Music sample credits

Every note of the walk's soundtrack (`src/game/music/`) is played on these
recordings. They are cut, trimmed, loudness-matched and re-encoded to mono MP3
by `scripts/music-samples.py`, which says exactly which source file each one
came from; the compositions themselves are original to this site.
